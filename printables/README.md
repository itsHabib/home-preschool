# Print-ready PDFs

These are rendered from the default `child.json` (name "Alex", pronouns "they"),
so you can print and play without installing anything.

- `binder.pdf`: the parent binder. A cover, one page on how to use the kit, the
  two skill ladders, and one page per week with the five activities, the book
  basket, the songs and the materials list.
- `kit-week-01.pdf`, `kit-week-02.pdf`, `kit-week-03.pdf`: one kit per week,
  eight pages each. Pages 1–5 are the play pages, one per day. Pages 6–8 are the
  pull-and-do parent cards: cut them out and keep the day's card by the fridge.

Print on US Letter, single-sided, at actual size (100%), with browser headers and
footers turned off. The play pages are black and white on purpose; the binder
uses color.

To put your own child's name on every page, edit `child.json`, then run
`npm run build` and `npm run pdf`. The PDFs here are regenerated by the same
command.
